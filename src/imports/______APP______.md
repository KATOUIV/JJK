# 咒术回战主题APP界面设计方案

## 一、整体设计规范

### 1\.1 色彩系统

基于咒术回战原作的视觉风格，结合官方衍生游戏的设计经验，我们定义了以下主题色彩体系：

|色彩名称|色值|应用场景|
|---|---|---|
|深幽黑|`\#1C1C1C`|主背景、卡片底色，营造咒术界神秘暗黑的氛围|
|咒术红|`\#AA0000`|主按钮、高亮元素、生命值进度条，代表咒术师的战斗意志|
|咒力绿|`\#008000`|咒力值进度条、术式相关标识，代表咒力的能量感|
|术式紫|`\#6A0DAD`|特殊术式、领域展开相关的强调色，代表稀有能力|
|高专金|`\#D4AF37`|标题文字、等级标识、装饰元素，代表高专的权威与高级感|
|晴空蓝|`\#4B92DB`|信息类次要强调、辅助文本，平衡暗黑风格的视觉疲劳|
|中性灰阶|`\#333333`/`\#666666`/`\#EEEEEE`|边框、次要文本、正文，保证内容的可读性|

### 1\.2 字体系统

为了贴合日式动漫风格同时保证长文本的可读性，我们采用以下字体方案：

- **标题字体**：`领域展开`，配合咒术回战专属艺术字效果，用于页面大标题，自带轻微的描边与光效，强化主题感

- **正文字体**：`方正楷体`，清晰的无衬线字体，用于剧情文本、设置项，保证长对话的阅读舒适度

- **状态数字字体**：等宽字体`times new roman`，用于属性数值、进度条数值，保证对齐与易读性

### 1\.3 通用界面元素

所有界面统一使用以下主题化元素，保证整体风格的一致性：

- **咒纹装饰**：所有卡片、输入框、按钮的边框，都使用简化的咒术封印纹路作为装饰，hover / 选中状态下纹路会触发咒力发光动效

- **功能图标**：所有功能入口的图标，都设计为咒术相关的主题图标：

    - 设置：咒印图标

    - 任务：咒术任务卷轴图标

    - 背包：咒术工具箱图标

    - 人际：双人咒术师图标

- **过渡动效**：页面切换时使用咒纹展开的过渡效果，按钮点击时触发咒力波动的动效，状态变化时添加数字跳动与光效反馈

### 2\.3 新游戏流程页面

新游戏是一个分步的引导流程，帮助用户完成自定义角色的创建，共分为 5 个步骤：

#### 2\.3\.1 难度选择页面

该页面用于选择游戏的难度，不同难度对应不同的初始属性点与游戏体验。

#### 页面布局：

1. **标题**：「选择你的咒术难度」，说明当前步骤

2. **难度卡片组**：水平排列的 5 个难度卡片，对应不同的挑战等级：

    |    难度名称|    对应等级|    初始属性点|    描述|
    |---|---|---|---|
    |    四级咒术师|    简单|    25|    适合初次踏入咒术界的新人，容错率极高，轻松体验剧情|
    |    三级咒术师|    普通|    20|    标准的咒术师体验，平衡的难度与剧情体验|
    |    二级咒术师|    困难|    15|    挑战较强的咒灵，需要合理规划属性与行动|
    |    一级咒术师|    噩梦|    10|    直面一级咒灵的威胁，稍有失误便会陷入危机|
    |    特级咒术师|    地狱|    5|    最强的挑战，初始属性极度匮乏，每一步都需要谨慎抉择|

3. **交互逻辑**：选中的卡片会高亮，边框变为咒术红，同时显示详细的难度说明，只有选中难度后才能点击下一步

#### 2\.3\.2 咒术师登记表页面

该页面用于填写角色的基础信息，同时完成属性点的分配。

#### 页面布局：

1. **标题**：「咒术师登记表」，对应原「冒险者登记表」

2. **左侧基础信息区**：

    - 姓名：输入框，填写你的咒术师名称

    - 年龄：数字输入框，填写角色年龄

    - 性别：单选框，支持男 / 女 / 未知三种选项

    - 人设：多行输入框，用于描述角色的性格、背景等自定义信息

3. **右侧属性加点区**：

    - 六边形雷达图：可视化展示 6 项咒术师属性的分配情况

    - 属性列表：

        - 体质（VIT）：影响生命值与抗打击能力

        - 敏捷（DEX）：影响行动速度与闪避能力

        - 力量（STR）：影响物理攻击力与肉搏能力

        - 咒力（CEP）：影响咒力最大值与术式基础威力

        - 术式适配（APT）：影响天生术式的成长上限

        - 精神力（MND）：影响对咒灵的精神抗性与意志力

    - 每个属性支持加减操作，总点数受之前选择的难度限制

4. **底部操作**：下一步按钮，完成信息填写后进入下一页

#### 2\.3\.3 咒术流派选择页面

该页面用于选择角色所属的咒术流派，不同流派对应不同的初始加成与剧情线。

#### 页面布局：

1. **标题**：「选择你的咒术流派」，对应原「种族选择」

2. **流派卡片组**：

    - **东京咒术高专**：正道咒术师的摇篮，初始正道名望 \+ 10，解锁高专专属任务线

    - **京都咒术高专**：传统咒术的传承者，初始战斗技巧 \+ 5，初始金钱 \+ 2000

    - **民间咒术师**：游离在体系外的强者，无初始阵营限制，可自由接取所有类型任务

    - **叛逃咒术师**：被高专驱逐的异类，初始邪道名望 \+ 10，解锁邪道专属任务线

    - **咒灵操使**：能够操控咒灵的特殊存在，初始解锁咒灵相关的特殊能力

3. **交互逻辑**：选中卡片后高亮，显示详细的初始加成说明，确认后进入下一步

#### 2\.3\.4 术式定义页面

该页面用于用户自定义自己的天生咒术术式，这是咒术回战的核心特色。

#### 页面布局：

1. **标题**：「定义你的咒术术式」

2. **术式信息表单**：

    - 术式名称：输入你的天生术式的名称

    - 术式属性：选择术式的属性，支持无、火、水、影、空间等多种选项

    - 术式描述：多行输入框，详细描述你的术式的能力、效果、限制

3. **扩展术式选择**：可勾选你已经掌握的基础扩展术式，比如黑闪、咒力强化、反咒术等

4. **底部操作**：下一步按钮，完成术式定义后进入经历生成页面

#### 2\.3\.5 开篇经历生成页面

该页面用于定义角色的过往经历，支持两种模式，对应原「选择经历方式」。

#### 页面布局：

1. **标题**：「定义你的过往经历」

2. **双模式卡片**：

    - **左侧：自定义开篇**：一问一答的对话模式，用户可以逐步描述自己的过往，LLM 会根据输入逐步生成对应的开篇剧情，适合想要高度自定义的用户

    - **右侧：自动生成过往**：根据用户之前所有的选择（难度、属性、流派、术式），自动生成完整的过往经历文本，用户可以直接编辑修改，适合快速开始游戏的用户

3. **确认按钮**：底部的「确认开启咒术人生」按钮，点击后将所有角色信息发送给 LLM，生成完整的开篇剧情，自动进入游戏主界面

### 2\.5 系统设置页面

用户点击「咒术系统设置」后进入该页面，用于配置 LLM 相关的系统参数，对应原系统设置的三个模块。

#### 页面布局：

1. **标题**：「咒术系统设置」

2. **功能卡片组**：三个功能卡片，点击进入对应的子设置页面：

    - **LLM API 设置**：配置对话模型的 API 参数，包括服务商选择、API 密钥、模型选择，同时支持分别配置正文回复与变量系统的 API，调整执行顺序

    - **咒术世界书**：配置咒术世界的背景信息，支持添加、编辑、删除世界书条目，让 LLM 更贴合咒术回战的世界观设定

    - **预设配置**：支持导入预设的角色、世界设定，比如官方的角色预设，或者其他玩家分享的自定义预设

3. **返回按钮**：底部的返回首页按钮

### 2\.6 游戏内主界面

这是用户进入游戏后的核心界面，用于剧情交互与状态查看，是整个应用的核心操作页面。

#### 页面布局：

1. **左侧侧边栏**：功能入口栏，垂直排列，每个入口为图标 \+ 文字的主题化设计：

    - 咒术师状态：查看完整的角色属性、状态信息

    - 任务清单：查看当前接取的所有任务

    - 人际档案：查看与各个 NPC 的好感、信任、关系状态

    - 咒术行囊：查看拥有的道具、装备

    - 术式技能：查看掌握的所有术式、战斗技能

2. **中间主交互区**：

    - **顶部信息栏**：显示当前的时间与地点信息，格式为：`2018年6月1日 14:00 周五 \| 东京都 咒术高专 操场`，该信息会根据剧情推进实时更新

    - **剧情文本区**：核心的剧情展示区域，滚动展示 LLM 生成的冒险纪行文本，带有打字机动效，增强沉浸感

    - **底部输入区**：用户输入框，用户可以在这里输入自己的行动、对话，与 LLM 进行交互，输入框同样带有咒纹边框

3. **右侧状态面板**：常驻的角色状态面板，实时展示核心状态：

    - 角色头像与名称

    - 等级与战力评级（根据等级自动更新，对应规则中的战力评级逻辑）

    - 生命值进度条：红色进度条，显示当前 / 最大生命值

    - 咒力值进度条：绿色进度条，显示当前 / 最大咒力值

    - 简要基础属性预览

    - EXP 进度条：显示当前的经验值进度，满值后自动升级

## 三、功能模块适配说明

本设计完全适配你提供的数据结构与变量规则，所有界面的状态都会严格按照规则实时更新：

1. **好感系统**：人际档案页面会实时更新 NPC 的好感度、信任度、关系阶段，严格遵循规则中的好感变化逻辑

2. **任务系统**：任务清单页面会按照规则记录任务的等级、类型、委托人、报酬等信息，正道任务提升正道名望，邪道任务提升邪道名望

3. **用户状态系统**：所有角色状态都会按照规则实时更新，比如 EXP 满 100 自动升级，每次升级获得 5KP，战力评级随等级自动变化，咒力、属性等状态实时同步

4. **变量更新**：所有界面的状态更新都严格遵循你定义的变量更新规则，时间、地点、状态等变量都会独立更新，保证数据的一致性
