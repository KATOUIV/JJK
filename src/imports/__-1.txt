---
变量更新规则:
  系统:
    时间:
      type: |-
        {
          年: number,
          月日: string,
          时分: string,
          星期: string
        }
      check:
        - 场景切换或行为导致时间流逝后更新，保持逻辑连贯。
        - 必须分别更新年、月日、时分、星期这四个独立变量，禁止将其合并为单一变量更新。
    地点:
      type: |-
        {
          国家: string,
          地域: string,
          场所: string,
          具体位置: string
        }
      check:
        - 仅当 user 发生位移或场景跳转时更新对应的层级。
        - 必须分别更新国家、地域、场所、具体位置这四个独立变量，禁止将其合并为单一变量更新。
    性爱状态:
      type: "{ 进行中: boolean, 参与者: string[] }"
      check:
        - 判定：仅在出现明确造成性快感的实质性行为时设为 true（暧昧行为不触发）
        - 结束：仅在 user 明确表现出结束意愿时设为 false
        - 开启时实时记录所有实际参与成员

  user:
    check:
      - 使用【降生】指令时，根据设定及消息全盘重置此对象。空变量自动根据user要求补全。
    等级:
      type: number
      check:
        - EXP ≥ 100 时提升等级
        - 快速连续升级规则：若结算后 EXP 大于等于 200、300 等整百倍数，则进行连续升级，EXP 每满 100 提升 1 级
        - 每次升级固定获得 5 KP，快速连续升级时获得升升级数乘以 5 的 KP（如连升 3 级获得 15 KP）
    EXP:
      type: number
      check:
        - 战斗结束或训练结束时提升，训练提升算法与战斗提升算法相同
        - 对同级咒灵（如一级咒术师/诅咒师对一级咒灵）胜利提升 50 EXP
        - 对同级术士（如一级咒术师对一级咒术师/诅咒师）胜利或与其训练提升 200 EXP
        - 对高一级的咒灵（如二级咒术师战胜一级咒灵）胜利提升 200 EXP
        - 对高一级的术士（如二级咒术师战胜一级咒术师/诅咒师）胜利或与其训练提升 500 EXP
        - 对低于自己等级的目标（无论咒灵还是术士）胜利或与其训练只提升 1 到 10 EXP
        - 快速结算规则：达到或超过 100 时，扣除消耗用于升级的整百倍数 EXP，清零当前层级并保留剩余的溢出值
    战力评级:
      check:
        - 随等级自动更新，无需手动干预
    公开身份:
      type: string[]
      check:
        - 仅在明确身份转变时添加，支持多个身份共存
    名望.${正道|邪道}:
      type: "{ 数值: number, 称号: string[] }"
      check:
        - 范围: -100 ~ 100
        - 数值：仅在以对应身份完成任务或公共活动时提升
        - 形容词：数值达到 20/40/60/80/100 阶段时变化
        - 名词：身份确实改变时同步添加/变化，支持并列（如：黑拳手、诅咒师）
    身体状况:
      check:
        - 随伤病、疲劳及实时状态更新
    咒力:
      type: "{ 当前值: number, 最大值: number }"
      check:
        - 使用术式消耗当前值；最大值除非消耗 KP 提升否则锁定
    永久损伤或疤痕:
      check:
        - 记录剧烈伤残及治愈后的疤痕；永久束缚代价需同步计入
    持有金钱 / 居住地:
      check:
        - 随报酬、消费或搬迁实时更新
    KP:
      type: number
      check:
        - 每升一级固定给 5 KP，保证在快速连续升级时得到对应的倍数 KP
        - 特定束缚时增加
        - 仅在明确支付购买能力时减少
    肉搏等级:
      check:
        - 仅在使用 KP 主动提升时变动，限定为S级、A级、B级、C级、未入门，五个等级，禁止变更为其他情况。
    当前服装:
      check:
        - 随换装或损毁状态实时更新
    行囊:
      type: "{ [名: string]: { 数量: number, 描述: string } }"
      check:
        - 获得/消耗物品时更新，数量归零则移除条目
    束缚:
      type: "{ [名: string]: { 代价: string, 恢复条件: string } }"
      check:
        - 明确宣告“结下束缚”时启用；判定永久或临时
        - 永久束缚恢复条件填“无”，其代价需同步记入“永久损伤”
    战技.${战技名} / 扩展术式.${术式名}:
      type: "{ 熟练度: number, 阶段: string, 描述: string }"
      check:
        - 习得/扩张新能力时添加；每次有效使用熟练度 +1
        - 阶段根据熟练度自动判定（入门/熟练/精通）
    生得术式:
      type: "{ 名称: string, 属性: string, 熟练度: number, 阶段: string, 描述: string }"
      check:
        - 除【降生】外设定锁定；仅熟练度随使用 +1/次
        - 阶段根据熟练度自动判定（入门/熟练/精通）
    特殊体质 / 咒灵操术:
      type: "{ [名: string]: string }"
      check:
        - 随获得/失去效果描述更新
        - 咒灵操术：进入死灭回游自动得“小金虫”；随调伏/吸收咒灵增加

  任务系统:
    type: |-
      {
        [任务ID: string]: {
          任务名: string,
          任务等级: '特级', '一级', '二级', '三级', '特殊',
          类型: '正道' | '邪道',
          委托人或势力: string,
          任务描述: string,
          完成条件: string,
          失败条件: string,
          报酬: { 金钱: number, 名望提升值: number, 物品: object }
        }
      }
    check:
      - 初始化要求：当 user 首次接取任务，且当前值为 '待初始化' 字符串时，需先将其覆盖为一个空对象 {}，随后将任务按格式作为新键值对插入
      - 记录要求：明确接取时必须完整填写每一栏（任务名、任务等级、类型、委托人或势力、任务描述、完成条件、失败条件、报酬），不得缺失
      - 任务类型说明：特级、一级、二级、三级都针对于需要祓除、击败咒灵或诅咒师等具有明确敌人的任务，除此以外任何关乎社交等非战斗因素的任务都属于'特殊'类型
      - 任务描述要求：精简描述任务内容、可能的风险以及需要完成的工作
      - 失败条件要求：委托方有额外要求才填，否则一律填“无”
      - 任务结束要求：当完成任务并向委托方结算报酬时，结算报酬并删除完成的这一任务。失败时不结算报酬，直接删除失败任务。
      - 名望报酬要求：同级(+2~5)，高一级(+10)，高二级(+20)
      - 阵营严格对应：正道任务仅提升正道名望，邪道任务仅提升邪道名望

  人际档案:
    type: |-
      {
        [NPC名: string]: {
          好感数值: number,
          信任度: number,
          关系阶段: string,
          欲望值: number
        }
      }
    check:
      - 人员管理：仅限本轮首次接触的有姓名角色新建档案；绝对禁止添加路人和无名角色；严禁删除已存在角色；严禁污染未接触的旧角色
      - 时间跳跃法则：当故事出现时间跳跃（如“一个月后”），强制执行公式【Δ数值=单日基调变化×天数】累加，严禁作为单次事件计算
      - 特殊变动限制：非 user 主动行为导致的好感度/信任度变动，皆视为搞笑日常，增减绝对值 ≤3
      - 好感度增加：基准值(+1赞美/礼物/趣闻, +3关心/帮助, +6陪伴/浪漫/转折/守护, +10救命/互助)；单次增加 max=10；阈值锁(若好感≥80且事件基准值<6，则+0)
      - 好感度扣减：基准值(-1轻微无礼, -5争执/忽略, -10恶意侮辱, -20间接伤害, -50决裂/背叛)；减分无视阈值锁，按剧情实扣，单次最低-50
      - 信任度增加：基准值(+1小承诺履行/小一致, +2可靠帮助/守秘, +3解决困境/单方守护/品格考验, +5双向生死/重大互救)；单次增加 max=5；阈值锁(若信任≥60且基准<3则+0；≥80且基准<6则+0)
      - 信任度扣减：基准值(-1小质疑/疏忽, -10谎言/欺骗, -20违背承诺, -50重大背叛/抛弃危局)；减分无视阈值锁，按剧情实扣，单次最低-50
      - 关系阶段：动态生成，保持个人化差异（如：兄弟、恋人等）。这是NPC/角色对user的看法，禁止掺杂user角度的描述，必须是“NPC当前怎么看user”。
      - 欲望值：正常不升；性暗示(+1~5)；性爱中(+1~20)；达100触发高潮并归零
